# Hotel Booking Analysis

This project focuses on analyzing hotel booking data to uncover patterns in guest behavior, booking trends, and operational performance. The goal is to help hotels reduce cancellations, optimize revenue, and improve guest satisfaction using data-driven insights.

## 🚀 **Project Highlights**
- Explored over 100,000 booking records across City and Resort hotels.
- Identified booking patterns by season, month, and customer type.
- Analyzed meal plan preferences, room type demand, parking needs, and special requests.
- Examined booking sources and their impact on cancellations and revenue.
- Built interactive dashboards in **Power BI** to visualize trends and support decision-making.
- Used **SQL**, **Excel**, and **Power BI** for data processing, analysis, and reporting.

## 📊 **Key Insights**
- **TA/TO (Travel Agents/Tour Operators)** brought the most bookings but had the highest cancellations.
- **Direct and Corporate bookings** were more stable, offering better revenue reliability.
- **Monsoon and Summer seasons** saw peak bookings; Winter had the lowest demand.
- The **₹50–100 ADR (Average Daily Rate)** segment was the most profitable and requested the most special services.
- City Hotels mostly served short-stay business guests; Resort Hotels attracted long-stay leisure travelers with higher repeat rates.

## 🛠 **Tech Stack**
- **SQL (MySQL Workbench)** – Data extraction, transformation, and analysis
- **Excel** – Exploratory data analysis (EDA) and pivoting
- **Power BI** – Interactive dashboards and visual analytics

## 📈 **Deliverables**
- Cleaned and transformed dataset ready for analysis
- SQL queries for booking trends, cancellations, ADR, and guest behavior
- Power BI dashboards covering:
  - Booking trends over time
  - Cancellation patterns
  - Meal and room preferences
  - Revenue and ADR insights
  - Booking source performance

## 🎯 **Outcome**
This project provides actionable insights for hotel managers to:
- Reduce cancellations
- Improve booking source strategies
- Enhance customer satisfaction
- Maximize revenue
